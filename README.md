# SistemaConsultorioJava

## Instalación y configuración

Para ejecutar este proyecto es necesario contar con Java JDK instalado, Git y un entorno de desarrollo compatible con Java, como IntelliJ IDEA o NetBeans.

## Uso del programa

El sistema permitirá registrar doctores y pacientes, así como crear citas médicas asociando un paciente con un doctor y una fecha determinada.
